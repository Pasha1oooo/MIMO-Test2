# MCGL — воксельная игра на C++17 / OpenGL 4.3

Клон Minecraft на чистом OpenGL (GLFW + epoxy, без ассетов: все текстуры генерируются процедурно).
Процедурная генерация мира (биомы, холмы, реки, озёра, деревья), динамическое освещение, вода,
день/ночь, ломание и установка блоков, крафт, мобы, мультиплеер по локальной сети.

## Сборка

Все библиотеки (GLFW, GLM, stb, glad) скачиваются и собираются автоматически
при первом запуске CMake — системные пакеты для них ставить не нужно.

Нужны только базовые инструменты сборки:

**Arch / Manjaro:**
```sh
sudo pacman -S --needed base-devel cmake git
```

**Ubuntu / Debian:**
```sh
sudo apt install build-essential cmake git
```

**Fedora:**
```sh
sudo dnf install gcc-c++ cmake git make
```

Дополнительно для сборки GLFW на Linux (заголовки X11; на Wayland-системах XWayland-заголовки всё равно нужны):

**Arch / Manjaro:**
```sh
sudo pacman -S --needed libx11 libxrandr libxinerama libxcursor libxi
```

**Ubuntu / Debian:**
```sh
sudo apt install libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev
```

**Fedora:**
```sh
sudo dnf install libX11-devel libXrandr-devel libXinerama-devel libXcursor-devel libXi-devel
```

Первый запуск (качает зависимости, ~1–2 минуты при медленном интернете):

```sh
cmake -B build
cmake --build build -j
```

Игра: `./build/game`

Сборка также требует Python3 (генератор glad, входит в base-devel/build-essential).

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | движение |
| Пробел | прыжок (до 3 блоков) |
| Shift | присесть |
| Ctrl | спринт |
| F | полёт (вверх/вниз — пробел/Shift) |
| ЛКМ | ломать блок (держать) |
| ПКМ | поставить блок |
| СКМ | выбрать блок из мира |
| E | инвентарь + крафт |
| 1–9, колесо | выбор слота хотбара |

| F5 | режим трассировки лучей (ray marching) |
| ESC | меню / закрыть инвентарь |

## Мультиплеер (до 4 игроков, локальная сеть)

Мир генерируется детерминированно — сервер и клиенты строят одинаковый террейн,
по сети передаются только правки блоков и позиции игроков. Мобы и погода живут локально
у каждого игрока.

Запуск сервера (на вашем компьютере):

```sh
./build/game --listen          # порт по умолчанию 35617
./build/game --listen 4000     # свой порт
```

Подключение друга (на его компьютере):

```sh
./build/game --connect ВАШ_IP           # порт 35617
./build/game --connect ВАШ_IP:4000      # свой порт
./build/game --connect 192.168.1.5 --name pasha
```

Узнать свой локальный IP: `ip addr` (адрес вида `192.168.x.x` или `10.x.x.x`).

Если компьютер за файрволом, разрешите входящие TCP-соединения на порт игры:

```sh
sudo ufw allow 35617/tcp        # Ubuntu/Manjaro (ufw)
# или включите порт в настройках firewalld / iptables
```

Одна машина — можно запустить сервер и два клиента подряд, все увидят друг друга.
До 4 игроков в сессии; правки блоков синхронизируются сразу, позиции — 15 раз в секунду.

## Режимы запуска (скрипты/тесты)

```sh
./build/game --shot out.png --frames 90          # скриншот вместо интерактивного режима
  --pos "x,y,z" --yaw 0.7 --pitch -0.3           # позиция/поворот камеры
  --time 0.3                                     # время суток (0..1)
  --rt 1                                          # включить трассировку лучей
  --outline 1                                     # включить аниме-обводку контуров
  --size 1920x1080                                # размер окна
```

## Структура

```
src/
  main.cpp   — окно, игровой цикл, ввод, UI, рендер мобов/игроков
  world.h    — генерация мира, чанки, свет, raycast
  mesher.h   — меш чанка (атлас 8x8 тайлов)
  player.h   — физика игрока
  mobs.h     — мобы (свиньи, зомби): спавн, ИИ, гравитация
  net.h      — TCP-мультиплеер: --listen / --connect
  blocks.h   — блоки, предметы, рецепты крафта
  ui.h       — хотбар, инвентарь, крафт-панель
  gfx.h      — GL-помощники, шрифты (stb_truetype), атлас
  shaders.h  — все шейдеры (GLSL 430)
  noise.h    — шуми/value noise/fBm/ridged
  common.h   — общие константы
```
